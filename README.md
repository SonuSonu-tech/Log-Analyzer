# Log Analyzer
Log is a single, time-stamped record of an event, action, or error generated by a computer system, application, server, or network device.
## Common type of log files:
- System Logs
- Application Logs
- Security Logs
- Network Logs
- Web Server Access and Error logs
## Log File Formats:
- Android
Format: ['Date', 'Time', 'Pid', 'Tid', 'Level', 'Component', 'Content']
- Windows
Format: ['Date', 'Time', 'Level', 'Component', 'Content']
- Linux
Format: ['Month', 'Date', 'Time', 'Level', 'Component', 'PID', 'Content']
- Mac
Format: ['Month', 'Date', 'Time', 'User', 'Component', 'PID', 'Address', 'Content']
- Apache
Format: ['Day', 'Month', 'Date', 'Time', 'Year', 'Level', 'Content']
- HDFS
Format: ['Date', 'Time', 'Pid', 'Level', 'Component', 'Content']
- BGL 
Format: ['Label', 'Timestamp', 'Date', 'Node', 'Time', 'Node Repeat', 'Type', 'Component',

- Handoop
Format: ['Date', 'Time', 'Level', 'Process', 'Component', 'Content']
- HPC
Format: ['Log Id', 'Node', 'Component', 'State', 'Time', 'Flag', 'Content']
- OpenSSH
Format: [ 'Date', 'Day', 'Time', 'Component', 'Pid', 'Content']
- OpenStack

# File Handling In Python
File handling allows Python to open, read, write, and manage files stored on a computer. In this project, file handling is used to access log files and read their records for analysis.

### Opening a File
Python provides built-in open() function to open a file.

```
file = open("logfile.txt", "r")
```
- logfile.txt: The name of the file to open.
- "r": The mode used to open the file for reading.

Some commonly used file modes are:

| Mode | Description 
| :--- | :---: 
| r | Opens a file for reading. The file must exist.
| w | Opens a file for writing. Creates a new file or overwrites an existing one.
| a | Opens a file for appending data to the end.
| x | Creates a new file and raises an error if it already exists.
| rb | Opens a file for reading in binary mode.

### Reading a file
Python provides different methods for reading file contents.
** read() — Read the entire file **
```
print(file.read())
```
This reads the remaining contents of the file as a single string.
**readline() — Read one line**
```
print(file.readline())
```
This reads the next line from the file.
**readlines() — Read all lines into a list**
```
print(file.readlines())
```
This returns the remaining lines as a list of strings.
